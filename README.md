## 🌐 Deploying to GitHub Pages

Since this is a static website (HTML/CSS/JS), hosting it on GitHub Pages is incredibly simple and entirely free.

### Step 1: Initialize Git and Push to GitHub
If you haven't uploaded this folder to GitHub yet, open your terminal in the `vivek-Portfolio-2k26` directory and run:

```bash
git init
git add .
git commit -m "Initial commit: Super Premium Cyber Portfolio"
git branch -M main
```

Then, create a new repository on GitHub (name it `vivek-Portfolio-2k26`). Copy the repository URL and link it:

```bash
git remote add origin https://github.com/vivekmishra26/vivek-Portfolio-2k26.git
git push -u origin main
```

### Step 2: Enable GitHub Pages

1. Go to your repository on GitHub.
2. Click on **Settings** (the gear icon near the top right).
3. On the left sidebar, scroll down to the "Code and automation" section and click on **Pages**.
4. Under the **Build and deployment** section, look for **Source**.
5. Select **Deploy from a branch**.
6. Under the **Branch** dropdown, select `main` (or `master`), and select the `/ (root)` folder. 
7. Click **Save**.

### Step 3: Wait for Deployment

GitHub Actions will now build and deploy your site. This usually takes 1-2 minutes. Once finished, at the top of the GitHub Pages settings screen, you will see a green banner with your live URL: 
`Your site is live at https://vivekmishra26.github.io/vivek-Portfolio-2k26/`
